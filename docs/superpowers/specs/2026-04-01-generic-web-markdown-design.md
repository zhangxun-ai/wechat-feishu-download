# 通用网页 Markdown 导出设计

**目标**

在保留飞书文档和微信公众号文章现有专用导出能力的前提下，为当前浏览器已打开的普通 `http/https` 网页增加单篇 Markdown 导出能力。

**范围**

- 支持当前活动标签页的普通网页单篇导出
- 保留飞书和微信公众号的现有专用提取逻辑
- 批量下载本轮仍只支持飞书和微信公众号链接
- 不支持 `chrome://`、`chrome-extension://`、本地文件页等特殊协议

**方案**

1. 弹窗将单篇导出识别范围扩展到普通 `http/https` 页面。
2. 内容脚本新增 `generic-web` 导出分支：
   - 提取标题、作者、发布时间等基础元信息
   - 优先在 `article`、`main`、`[role=main]`、常见正文 class/id 中寻找正文容器
   - 找不到时回退到文本密度更高的节点，最终回退到 `document.body`
3. 通用网页导出沿用现有 HTML 转 Markdown 转换器，并在导出前移除导航、页脚、侧栏、表单、弹窗等明显噪音。
4. 通用网页图片默认保留原始链接，不转 `data:` URL，避免扩大权限和性能开销。

**权衡**

- 选择内置轻量规则而不是引入第三方正文抽取库，优先保持扩展结构简单。
- 正文识别以“可读优先”为准，不承诺样式完全还原。
- 对高度动态的 SPA 页面，仅处理用户已在当前页面加载出来的内容。
