# 生财课程专栏整包导出设计

**目标**

在不影响现有单篇导出、手工批量下载、公众号后台模式的前提下，为 `scys.com/deepsea/.../course/...?...chapterId=...` 页面新增“导出当前专栏”能力。用户在任一专栏章节页点击后，扩展自动识别当前专栏左侧目录中的全部章节，逐章抓取正文，并最终输出两个单文件结果：

- `专栏名.md`
- `专栏名.html`

其中：

- `Markdown` 面向 NotebookLM、Obsidian、AI 分析、全文搜索和二次整理
- `HTML` 面向离线浏览，提供接近网页端的目录导航体验

**范围**

- 新增一个独立入口：`导出当前专栏`
- 第一版只支持当前生财课程专栏页面
- 只处理当前专栏左侧目录中实际可访问的章节
- 最终固定输出单个 `Markdown` 与单个 `HTML`
- 复用现有任务页执行批量抓取与进度展示

**非目标**

- 不替代现有“导出当前页 Markdown”
- 不改动现有“批量下载链接列表”能力
- 不支持整个课程专区、整个站点或多专栏全量遍历
- 不输出 PDF
- 不复刻原站完整样式，只保留目录导航与正文可读性

## 用户体验

### 入口

当当前标签页匹配生财课程章节页时，弹窗在现有按钮之外额外显示一个新按钮：

- `导出当前专栏`

旧功能保持原位，原有文案与行为不变。

### 交互流程

1. 用户在任一专栏章节页打开扩展弹窗
2. 弹窗检测页面为支持的专栏章节页后，显示 `导出当前专栏`
3. 点击后，扩展从当前页面提取：
   - 专栏标题
   - 课程或专栏标识
   - 当前左侧目录章节列表
   - 当前章节信息
4. 弹窗创建一个新的批量任务，并打开现有任务页
5. 任务页逐章抓取并实时显示日志、进度、成功数、失败数
6. 任务完成后自动下载：
   - `专栏名.md`
   - `专栏名.html`

### 成功标准

- 用户不需要手工整理链接
- 扩展能自动发现当前专栏大部分章节
- 输出单个 Markdown 可直接投喂 AI 或导入 Obsidian
- 输出单个 HTML 可本地打开，并通过左侧目录浏览章节

## 架构方案

### 总体思路

采用“目录发现 + 逐章导出 + 最终合并”的新增任务模式，而不是修改现有单篇导出或手工批量逻辑。

这意味着：

- 当前页导出逻辑继续只处理单个已打开页面
- 现有手工批量逻辑继续处理用户输入的一组链接
- 当前专栏导出通过一个新任务类型 `course-export` 复用任务页框架

### 为什么不直接枚举 `chapterId`

不采用“猜测或遍历 chapterId”的方式，原因如下：

- `chapterId` 不保证连续
- 站点可能存在隐藏章节、无权限章节、已下线章节
- 目录顺序应以页面真实目录为准，而不是以 ID 数值排序
- 读取当前页面左侧目录的真实数据比构造 URL 更稳

### 模块拆分

1. `popup`
   - 检测当前页是否为支持的生财课程章节页
   - 显示新增按钮
   - 请求内容脚本解析当前专栏目录
   - 创建并存储 `course-export` 任务

2. `content script`
   - 新增站点专用目录解析能力
   - 从当前页面读取专栏标题与章节列表
   - 继续承担单章节正文导出能力

3. `batch runner`
   - 支持新任务类型 `course-export`
   - 顺序打开每个章节页面
   - 调用现有页面导出消息抓取单章内容
   - 合并生成单个 Markdown 与单个 HTML

4. `shared helpers`
   - 站点 URL 识别
   - 章节链接标准化
   - 合并输出时的标题、锚点、目录生成

## 目录发现设计

### 识别条件

当 URL 匹配 `https://scys.com/deepsea/.../course/...` 且包含 `chapterId` 参数时，视为潜在专栏章节页。

### 解析策略

优先级如下：

1. 优先读取页面中的结构化前端状态对象
2. 如无稳定状态对象，则解析左侧目录 DOM
3. 如仍失败，则返回“未识别到当前专栏目录”

提取出的章节结构统一标准化为：

```json
{
  "courseTitle": "CLI类AI编程工具速通",
  "courseUrl": "https://scys.com/deepsea/2001/course/164?chapterId=11093",
  "chapters": [
    {
      "order": 1,
      "title": "前言",
      "chapterId": "11093",
      "url": "https://scys.com/deepsea/2001/course/164?chapterId=11093"
    }
  ]
}
```

### 顺序规则

- 以左侧目录读取顺序为唯一可信顺序
- 不按 `chapterId` 数值排序
- 目录中的分组标题与真实章节需要区分
- 仅将可访问章节加入导出列表

## 抓取流程设计

### 任务载荷

新增任务类型：

```json
{
  "type": "course-export",
  "title": "生财课程专栏导出 - CLI类AI编程工具速通",
  "source": "scys-course",
  "courseTitle": "CLI类AI编程工具速通",
  "chapters": [
    {
      "order": 1,
      "title": "前言",
      "chapterId": "11093",
      "url": "https://scys.com/deepsea/2001/course/164?chapterId=11093"
    }
  ],
  "includeImages": true
}
```

### 单章抓取

对每个章节：

1. 在后台打开章节页
2. 等待页面完成导航和渲染稳定
3. 调用现有内容脚本导出当前页正文
4. 获取该章 `markdown`、标题、来源链接
5. 关闭后台标签页

这里复用现有“打开页面 -> 注入内容脚本 -> 调用 `feishu-export:export-document`”链路，不新增第二套正文抽取器。

### 页面稳定策略

生财课程页本质上属于前端渲染页面，因此抓取每章时需要额外稳定等待：

- 等待标签页 `complete`
- 额外等待固定缓冲时间
- 如有必要，检测正文容器是否已出现
- 单章失败后进入重试

## 合并输出设计

### Markdown 输出

Markdown 结构如下：

1. 文档头
   - 专栏标题
   - 原始专栏入口链接
   - 导出时间
   - 成功章节数 / 失败章节数
2. 自动目录
3. 各章节正文
   - 每章标题
   - 原文链接
   - 清晰分隔
4. 失败章节列表

示例结构：

```md
# CLI类AI编程工具速通

来源：<专栏链接>
导出时间：2026-04-20T00:00:00.000Z
成功：18 章
失败：2 章

## 目录

- [前言](#前言)
- [MCP 里有三个角色，你需要知道](#mcp-里有三个角色你需要知道)

---

## 前言

原文：<章节链接>

章节正文...
```

设计原则：

- 对 AI、Obsidian、NotebookLM 友好
- 不依赖扩展运行环境
- 结构尽量平整，避免复杂嵌套

### HTML 输出

HTML 为单文件离线阅读版，包含：

- 左侧固定目录
- 右侧正文区域
- 章节锚点跳转
- 基础排版样式
- 失败章节提示区

设计原则：

- 不加载外部脚本和样式
- 单文件可直接双击打开
- 可读性优先，不追求原站 UI 复刻

### 命名规则

最终输出：

- `专栏名.md`
- `专栏名.html`

文件名继续复用现有安全命名策略，处理非法字符与重名问题。

## 错误处理

### 目录识别失败

- 弹窗直接提示：`未识别到当前专栏目录`
- 不影响现有单篇导出

### 部分章节失败

- 任务继续执行后续章节
- 最终仍生成单个 Markdown 和单个 HTML
- 在文档头和文档尾部记录失败数与失败列表

### 单章正文为空

- 记为该章节失败
- 日志中标记对应章节标题和 URL
- 不阻断整个专栏导出

### 顺序异常

- 永远以当前目录读取顺序为准
- 不做额外重排

## 兼容性与回归约束

为了保证“新增功能、不影响之前功能”，实现时必须遵守以下约束：

- 现有 `导出 Markdown` 按钮行为不变
- 现有 `批量下载链接列表` 逻辑不变
- 现有公众号后台模式逻辑不变
- 新能力必须通过明确的新按钮或新任务类型进入
- 通用网页单篇导出逻辑不因生财专栏支持而改变行为

## 验证计划

### 功能验证

1. 在生财课程章节页打开弹窗
2. 看到新增按钮 `导出当前专栏`
3. 点击后成功创建任务页
4. 任务页识别并显示章节总数
5. 最终下载：
   - `专栏名.md`
   - `专栏名.html`

### 内容验证

- Markdown 中章节顺序与网页左侧目录一致
- HTML 可本地打开，左侧目录可跳转
- 每章保留原文链接
- 失败章节出现在失败列表中

### 回归验证

- 飞书单篇导出可用
- 微信公众号单篇导出可用
- 普通网页单篇导出可用
- 手工批量下载链接功能可用
- 公众号后台模式可用

## 实现顺序建议

1. 增加生财课程页识别与目录提取
2. 在弹窗增加 `导出当前专栏` 入口
3. 在任务页支持 `course-export` 新任务类型
4. 逐章抓取并保存中间结果
5. 合并生成单个 Markdown 与单个 HTML
6. 运行回归验证

## 已知风险

- 生财页面 DOM 或前端状态结构未来可能变化
- 章节内容如果依赖更长时间的异步加载，稳定等待可能需要调整
- 某些章节若有权限控制，可能无法在后台标签页完整抓取

第一版接受这些风险，但要求错误可见、失败可追踪、整体任务不中断。
