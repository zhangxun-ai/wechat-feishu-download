# 文档本地导出 - 隐私政策

最近更新：2026-03-24

## 1. 插件用途

本插件用于将以下内容导出到用户本地设备：

- 飞书 `docx/wiki` 文档
- 微信公众号文章
- 用户在当前 Chrome 浏览器中已登录的微信公众号后台历史文章列表

## 2. 我们处理哪些数据

插件只处理完成功能所必需的数据，包括：

- 当前页面中的文档内容、文章正文、图片链接
- 用户在插件中输入的文章链接、日期范围等操作参数
- 浏览器本地保存的插件设置，例如是否包含图片

## 3. 数据如何使用

这些数据仅用于以下目的：

- 将页面内容导出为 Markdown
- 批量下载用户明确选择的文章
- 在用户已登录公众号后台时，查询并下载指定日期范围内的历史文章

## 4. 数据存储与传输

- 插件默认将导出结果保存到用户本地下载目录
- 插件使用 `chrome.storage.local` 保存本地设置和批量任务信息
- 插件不会将飞书文档正文、公众号正文、批量下载结果上传到开发者服务器

## 5. 第三方服务与网络请求

插件会直接访问以下用户正在使用或用户明确触发的站点：

- `feishu.cn`
- `larksuite.com`
- `larkoffice.com`
- `mp.weixin.qq.com`
- 微信文章中使用到的图片资源域名

这些请求仅用于读取页面内容、查询公众号后台历史文章或下载文章内图片资源。

## 6. 我们不做的事情

- 不出售用户数据
- 不将文档正文或文章正文上传到开发者自有服务
- 不做广告追踪
- 不读取与插件功能无关的网页内容

## 7. 用户控制

用户可以随时：

- 卸载插件
- 删除浏览器下载目录中的导出文件
- 清除 Chrome 扩展本地存储中的设置与任务记录
