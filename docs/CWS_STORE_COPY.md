# Chrome Web Store 文案

## 名称

文档本地导出

## 简短说明

将飞书文档和微信公众号文章导出到本地 Markdown，并支持按时间范围批量下载同公众号历史文章。

## 详细描述

文档本地导出是一款面向内容整理、资料归档和知识库沉淀的 Chrome 扩展。

它可以帮助你把常见内容直接保存到本地，减少手动复制整理的时间。

当前支持：

- 飞书 `docx/wiki` 文档导出到本地 Markdown
- 微信公众号文章导出到本地 Markdown
- 在当前 Chrome 已登录 `mp.weixin.qq.com` 的前提下，按时间范围批量下载同公众号历史文章
- 批量任务自动打包下载
- 可选择是否包含正文图片

适合场景：

- 个人知识库归档
- 内容复盘与资料整理
- 课程资料沉淀
- AI 分析前的文本整理

使用说明：

1. 打开支持的飞书文档或微信公众号文章页面
2. 点击扩展图标
3. 选择导出当前页面，或执行批量下载
4. 文件会保存到浏览器默认下载目录

注意事项：

- 公众号范围下载需要你先在当前 Chrome 中登录 `mp.weixin.qq.com`
- 导出结果默认保存到本地，不会上传文档正文或文章正文到开发者服务器
- 实际可导出效果取决于当前页面是否可正常访问
