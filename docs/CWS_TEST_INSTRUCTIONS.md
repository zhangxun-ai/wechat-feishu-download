# Chrome Web Store 审核测试说明

## 插件用途

本扩展用于将飞书文档和微信公众号文章导出到用户本地设备，并支持在当前 Chrome 已登录微信公众号后台的前提下，按时间范围批量下载同公众号历史文章。

## 如何测试飞书单篇导出

1. 打开任意飞书 `docx` 或 `wiki` 页面
2. 点击扩展图标
3. 点击“导出 Markdown”
4. 检查浏览器默认下载目录中是否出现 Markdown 文件

## 如何测试微信公众号单篇导出

1. 打开任意微信公众号文章页面
2. 点击扩展图标
3. 点击“导出 Markdown”
4. 检查浏览器默认下载目录中是否出现 Markdown 文件

## 如何测试公众号历史范围下载

1. 先在当前 Chrome 中登录 `https://mp.weixin.qq.com/`
2. 打开任意一篇公众号文章页面
3. 点击扩展图标
4. 在“公众号后台模式”中填写开始日期和结束日期
5. 点击“按范围批量下载”
6. 检查浏览器默认下载目录中是否出现批量下载结果

## 测试注意事项

- 公众号范围下载依赖当前 Chrome 中的 `mp.weixin.qq.com` 登录态
- 如果未登录公众号后台，插件界面会提示先登录再执行范围下载
- 导出文件默认保存到浏览器默认下载目录
